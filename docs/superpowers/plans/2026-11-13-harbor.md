# Harbor Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for inline implementation with a fresh whole-project review.

**Goal:** Deliver the final UHI Return Delta Hooks quest as a public, tested custom-curve internal swap pool.
**Architecture:** HarborMath implements amplified virtual-reserve pricing; HarborHook owns ERC-6909-backed reserves and ERC20 LP shares; HarborRouter provides actual amount slippage/deadline checks.
**Tech Stack:** Solidity 0.8.26, Cancun, Foundry 1.5.0, pinned v4-core and OpenZeppelin.
**Spec:** ../specs/2026-11-13-harbor-design.md

## Global Constraints

Separate return-delta-hook repository; prior quests unchanged. One immutable sorted pair, two nonzero standard 18-decimal ERC20s, fee=0 and tickSpacing=60 in the native key, initialization Q96. Virtual offset 9*LP supply, 0.10% input fee retained, swap reserve floor ceil(S/10), reserve/supply cap uint112.max. Exact input and exact output in both directions. No oracle/admin/proxy/native ETH/public-chain funds. Append research to workspace RESEARCH.md.

## Review Focus

- Full specified cancellation with correct signs in both trade modes: inspect returned deltas, actual token movements and zero native liquidity.
- Claim/reserve/share conservation through token callbacks and reverted settlement: backing checks and hostile token regression.
- Exact-output rounding and buffer boundary: inverse quotes, minimal gross input and boundary tests.
- LP share inflation/donation and last withdrawal: explicit tracked reserves, repeated deposits, donated claims ignored, complete exit/reseed.
- Native price limit is not custom-curve slippage: router limits and deadlines checked on actual results.
